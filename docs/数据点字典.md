## 数据点命名规范

1. **命名空间**: `NAMESPACE.PointName` (点号分隔)
2. **风机编号**: `TURBINE_NNN` (3位补零, 000-099)
3. **嵌套子字段**: `TURBINE_NNN.FieldName`
4. **大小写**: PascalCase
5. **禁止特殊字符**: 仅允许 `[A-Za-z0-9_.]`

## 使用说明

### 1. 启动RT_DB守护进程
```bash
# Windows（VS2022 Developer Command Prompt）
cd 风电AGC
build\bin\Release\rt_db_init.exe
```

守护进程启动后：
- 初始化 20000 数据点容量的共享内存
- 预注册全部 869+ 个命名数据点
- 每 5 秒打印状态：`[Status] Clients: X, Total Writes: Y, Rate: Z writes/sec`
- `Ctrl+C` 优雅退出

### 2. 启动统一AGC Daemon（读取+写入共享内存）

```bash
build\bin\Release\unified_agc.exe
```

Daemon 运行时的数据流：
- **输入通道**（独立 `rt_db_handle_t`）: 读取 `GRID.Frequency`, `WIND_AGC.WindSpeed`, `COMM.IsHealthy`, `EXTREME.SubType`, `CURTAIL.Ratio`, `WIND_AGC.SchedulePower`
- **输出通道**（UnifiedLogger）: 写入 `WIND_AGC.TotalPower`, `.SchedulePower`, `.Setpoint`, `.ErrorPU`, `.Mode`, `.CycleCount`, `GRID.Frequency`, `SAFETY.CurrentMode`, `COMM.IsHealthy`, `SAFETY.FrozenPowerMW`, `CURTAIL.Ratio`, `.ReserveUp`, `.ReserveDn`, `EXTREME.SubType`

### 3. 在场景代码中注册数据点
```cpp
// 继承RtDbLoggerBase
class MySceneLogger : public common::RtDbLoggerBase {
protected:
    void buildPointIndexMap() override {
        registerPoint("WIND_AGC.TotalPower", &idxTotalPower_);
        registerPoint("TURBINE_000.Power", &idxTurbine0Power_);
        // ...
    }
};
```

### 4. 指令队列格式
```c
ControlCommand cmd = {
    .device_id = "WIND_AGC",
    .command_type = 1,   // 1=STEP, 2=RAMP, 3=CANCEL
    .value = 70.0,        // 目标功率 MW
    .priority = 1,
};
rt_db_push_command(handle, &cmd);
```

### 5. HIL 测试中使用数据点

HIL Runner（`tools/data_generator/runner.cpp`）直接通过 `rt_db_set_value` / `rt_db_get_value` 读写数据点：

**Runner 写入的输入点:**
- `GRID.Frequency` — 模拟电网频率变化
- `WIND_AGC.WindSpeed` — 模拟风速变化
- `WIND_AGC.FluctuationWarning` — 触发波动预警
- `COMM.IsHealthy` — 模拟通信中断/恢复
- `EXTREME.SubType` — 触发极端天气
- `CURTAIL.Ratio` — 设置限电比例
- `WIND_AGC.SchedulePower` — 调度计划功率
- `WIND_AGC.Setpoint` — AGC指令目标

**Runner 读取的输出点:**
- `WIND_AGC.TotalPower` — AGC 实际输出功率
- `WIND_AGC.Setpoint` — AGC 计算的目标指令
- `WIND_AGC.Mode` — 当前场景编号 (1-6)
- `GRID.Frequency` — 频率（验证恢复过程）
